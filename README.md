DailyDish – Recipe Book Website

DailyDish is a simple and visually appealing recipe book website designed to help users discover, explore, 
and learn different recipes in an easy and organized way.
The website provides a clean interface where users can browse recipes, view recipe details, and follow cooking instructions 
step by step.

Technologies Used
HTML5 – Structure of the website
CSS3 – Styling and layout
JavaScript – Interactivity and dynamic functionality
Bootstrap 5 – Responsive design and UI components

The main objective of DailyDish is to create a simple digital recipe book that makes discovering and following recipes convenient.
The project also demonstrates the use of HTML, CSS, JavaScript, and Bootstrap to create an interactive and responsive website.

DailyDish was developed as a web development project to demonstrate frontend design, 
responsiveness, and JavaScript-based interactivity.
